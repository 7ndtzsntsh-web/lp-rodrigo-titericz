# Rodrigo Titericz — site

Site do advogado Rodrigo Titericz (OAB/SC 11.670), Florianópolis/SC. Feito pela Vanguard Web Studio.
No ar: https://lp-rodrigo-titericz.vercel.app

```bash
npm install
npm run build          # CSS + versão nos nomes dos arquivos + verificações
npm run dev            # http://localhost:4321 com os mesmos cabeçalhos de segurança da Vercel
npm run security:scan  # Observatório da MDN contra o servidor local (com o dev rodando)
```
